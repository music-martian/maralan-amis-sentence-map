# 馬蘭阿美語 · 句型圖

Interactive sentence maps for **馬蘭阿美語 (Maralan Amis)** — greetings unit from Klokah junior class 16.

- **Learn:** full SVG maps with Amis labels + color legend  
- **Practice:** Chinese/English shown; tap colored pills to reveal Amis  
- **Audio:** 🔊 plays Klokah exchange clips  

## Live site

After GitHub Pages is on:  
`https://music-martian.github.io/maralan-amis-sentence-map/`

## Open locally

Open `index.html`, or:

```bash
python3 -m http.server 8765
```
